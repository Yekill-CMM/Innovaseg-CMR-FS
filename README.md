# CRM FS

Versión multiusuario del CRM Comercial para First Security (producto de Innovaseg).

## Configuración por defecto

`config/config-crm.default.json` tiene los valores con que parte una instalación nueva:
UF y USD de referencia, plazos por tipo de oportunidad, umbrales de seguimiento,
inactividad de clientes, prospectos y oportunidades, vencimiento de ofertas y la base
de cálculo de metas (`metaBase`). No lleva datos reales ni claves.
